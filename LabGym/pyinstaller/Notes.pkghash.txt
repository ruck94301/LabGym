The LabGym.pkghash package is written to walk the LabGym tree for 
py-files and produce a hash, and look up that hash in versions.toml.

But in a pyinstaller build,
*   no py-files are located, so the hash is d41d... because 0 bytes.
*   versions.toml isn't included in the build by default.

For inspiration re storing a fixed hash when compiling with pyinstaller,
see 
*   https://www.google.com/search?q=python+to+test+if+current+program+is+being+run+from+python+interpreter+or+from+pyinstaller+build
*   https://github.com/pyinstaller/pyinstaller/issues/1818#
*   https://gist.github.com/JarekParal/24e15de33971674a8c0f9955f6ad15e0
